# 听写历史记录逻辑优化

## 修改目标

✅ 一局听写（包括所有重试轮次）只占用一条历史记录

## 修改内容

### 1. 修改 `js/dictation/history.js`

#### 新增 `updateHistory()` 函数
```javascript
export function updateHistory(id, updates)
```
- 根据记录ID更新已存在的历史记录
- 保持ID不变，只更新内容字段

#### 修改 `saveHistory()` 函数
- 返回新创建记录的ID
- 用于后续更新同一条记录

### 2. 修改 `js/dictation/index.js`

#### 在 state 中添加 `sessionHistoryId` 字段
```javascript
this.state = {
    // ... 其他字段
    sessionHistoryId: null  // 当前听写会话的历史记录ID
}
```

### 3. 修改 `js/dictation/quiz.js`

#### 导入 `updateHistory` 函数
```javascript
import { saveHistory, updateHistory } from './history.js';
```

#### 修改 `showResults()` 函数的保存逻辑
```javascript
if (s.sessionHistoryId) {
    // 已有历史记录ID，更新现有记录
    updateHistory(s.sessionHistoryId, historyRecord);
} else {
    // 首次保存，创建新记录
    const newId = saveHistory(historyRecord);
    s.sessionHistoryId = newId;
}
```

## 工作流程

### 场景1：首次听写完成（无重试）
1. 用户完成听写
2. `showResults()` 被调用
3. `sessionHistoryId` 为 null
4. 调用 `saveHistory()` 创建新记录
5. 记录ID保存到 `s.sessionHistoryId`

### 场景2：首次听写 + 重试
1. 用户完成首次听写
2. `showResults()` 创建新历史记录（ID: abc123）
3. `s.sessionHistoryId = "abc123"`
4. 用户点击"错题重听"
5. 完成第一次重试
6. `showResults()` 再次被调用
7. 检测到 `s.sessionHistoryId = "abc123"`
8. 调用 `updateHistory("abc123", newData)` **更新同一条记录**
9. 历史记录列表中只有1条记录，但包含所有轮次的数据

### 场景3：多次重试
1. 首次听写 → 创建记录 (ID: abc123)
2. 第1次重试 → 更新记录 abc123
3. 第2次重试 → 更新记录 abc123
4. 第3次重试 → 更新记录 abc123
5. **历史记录列表中始终只有1条记录**

## 关键改进

### 之前的问题
- ❌ 每次重试都创建新记录
- ❌ 一局听写可能占用多条历史记录
- ❌ 很快就会超过10条限制

### 现在的逻辑
- ✅ 首次 `showResults()` → 创建新记录
- ✅ 重试后 `showResults()` → 更新同一条记录
- ✅ 一局听写始终只占用1条历史记录
- ✅ 历史记录显示最新的分数和完整的重试过程

## 测试步骤

1. **测试首次听写**
   - 输入一些单词
   - 完成听写（全部正确）
   - 悬浮在"听写"按钮查看历史
   - ✅ 应该看到1条新记录

2. **测试首次听写 + 重试**
   - 输入一些单词
   - 故意答错几个单词
   - 完成首次听写
   - 查看历史 → 应该有1条记录
   - 点击"错题重听"
   - 完成重试
   - 再次查看历史 → **仍然只有1条记录**
   - 点击这条记录 → 应该看到完整的两轮答题过程

3. **测试多次重试**
   - 完成首次听写（有错误）
   - 第1次重试（仍有错误）
   - 第2次重试（全部正确）
   - 查看历史 → **仍然只有1条记录**
   - 点击记录 → 应该看到所有3轮的完整过程

4. **测试10条限制**
   - 完成10局不同的听写（每局可能包含多次重试）
   - 查看历史 → 应该有10条记录
   - 完成第11局听写
   - 查看历史 → 仍然只有10条记录（最旧的被移除）
